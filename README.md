# Procedural Sedation Simulation Training website

This folder contains a static, mobile-responsive one-page website based on the approved visual mock-up.

## Files
- `index.html` – page structure and content
- `styles.css` – design and responsive layout
- `assets/hero-resus.png` – hero image cropped from the supplied approved template
- `assets/course-logo.png` – course logo cropped from the supplied approved template
- `assets/college-logos.png` – RCoA / RCEM visual block from the supplied template
- `assets/trust-logo.png` – MTW NHS Trust footer visual from the supplied template

## Registration
All registration buttons currently point to the existing Google Form.

## Publishing
The folder can be published as a static site on any standard static host. Upload the contents of this folder with `index.html` at the top level.

## Updating course dates
Open `index.html`, search for `Upcoming course dates`, and edit the six `.date-row` entries. Availability badges can use either `badge` or `badge wait`.

## Images and logos
Before public launch, confirm you have permission to use the RCoA, RCEM, NHS and Trust logos in this context. If needed, replace the cropped graphics with official approved brand assets.
